# AcousticSpace – Deepfake Audio Detection

## Project Overview
AcousticSpace is a project focused on detecting deepfake audio using Room Impulse Response (RIR) analysis.

## Objectives
- Analyze uploaded audio files.
- Study acoustic and room-response features.
- Develop a machine learning model for deepfake audio detection.
- Display detection results through a user-friendly interface.

## Technologies
- Python
- Machine Learning
- Audio Signal Processing

## Project Status
Initial project setup completed. Model development and testing are subject to implementation.

## How to Run
Run the Python application using the appropriate command for the project entry-point file.
